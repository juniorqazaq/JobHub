# Company logo sources

The vacancy presentation registry uses the original assets below. Each file is stored locally in `frontend/public/company-logos/` so vacancy pages do not depend on a third-party asset request at runtime.

| Company | Local asset | Official source |
| --- | --- | --- |
| Kcell | `kcell.svg` | <https://jobs.kcell.kz/assets/KcellJobsLogo-CjPToti-.svg> |
| Air Astana | `air-astana.svg` | <https://job.airastana.com/assets/images/icons/air-astana-gray.svg> |
| Halyk Bank | `halyk-bank.svg` | <https://halykbank.kz/storage/app/uploads/public/6a5/75a/f7a/6a575af7a9880610279451.svg> |
| Technodom | `technodom.svg` | <https://www.technodom.kz/images/global/logo_technodom_text.svg> |
| Kolesa Group | `kolesa-group.svg` | The official site loads the SVG through <https://kolesa.group/_nuxt/kolesa-group.3418b555.js>; its component manifest is <https://kolesa.group/_nuxt/Icon.ae92976b.js>. |

The artwork is unmodified. Only its rendered size is constrained by JobHub layout styles.
